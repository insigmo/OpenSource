
# Rust Reimplementations of Popular Software

A collection of Rust-based alternatives and independent reimplementations of popular commercial software.

The goal is to discover projects that recreate the functionality of well-known applications using Rust, often with AI-assisted development.

> Note: Not every project is a 1:1 replacement. Some are early-stage alternatives or independent implementations. Check each repository for its current status.
